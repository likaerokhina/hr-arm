# UX-референсы и visual direction

## Направление: Modern Enterprise + AI-accent

Не клон Huntflow, не «AI wow» — знакомая структура + свой визуальный язык.

## Токены (как в `styles.css`)

| Элемент | Значение | Где используется |
|---------|----------|------------------|
| Шрифт | Plus Jakarta Sans | Весь UI |
| Фон страницы | Warm off-white `#f7f6f4` | Main area |
| Surface | White `#ffffff` | Карточки, sidebar, колонки pipeline |
| Primary | Indigo `#4f46e5` | CTA, active nav, ссылки, AI-акценты |
| Primary soft | `#eef2ff` | Hover/active sidebar, KPI-иконки, badge AI |
| Sidebar | Light `#ffffff`, border-right | Левое меню продукта |
| Sidebar active | `primary-soft` bg + primary text | Текущий пункт навигации |
| AI gradient | `#6366f1` → `#8b5cf6` | Score ring, badge «AI-подбор» |
| Stage colors | violet / amber / green / slate | Top-border колонок воронки |
| Radius | 12px cards, 8px controls | Карточки, кнопки, inputs |

## Платформы-референсы

| Платформа | Что взяли |
|-----------|-----------|
| [Huntflow](https://huntflow.ru) | 3 колонки: вакансии → воронка → карточка; застой, отказы |
| HellowHR | Внутренний опыт команды — те же HR-привычки |
| [Ashby](https://docs.ashbyhq.com/candidate-pipeline) | Pipeline stages + count badges |
| AppSheet (внутр.) | Банк резюме: календарь занятости, % загрузки, фильтр «свободны» |
| SaaS 2026 | Light sidebar, KPI cards, card-list (не dark theme) |

**Принцип:** не копируем экраны один в один — **переносим привычные сигналы** в наш UI (см. макеты и эпики в `arch`).

### Что адаптировали из «коробок» в наш интерфейс

| Откуда (типично в ATS) | Как у нас в макете |
|------------------------|-------------------|
| Дней в работе / просрочка | «N дн. в статусе», badge «горит» на списке вакансий — **в макете** |
| Rejection reason | «Отказ · причина» в воронке (колонка «Отправлено») и на экране истории — **в макете** |
| Кандидат занят | «Занят до …» на карточке воронки — **в макете** |
| Activity log | Лента по вакансии + мини-лента «Последние шаги» в карточке кандидата — **в макете** |
| CV как файл | Скачать DOCX по шаблону (подпись на экране резюме) — **в макете** |

## Экраны (presale)

Скрины — в [образе результата](../arch/docs/product/obraz-rezultata.md#экраны-лк). Ниже — паттерны по экранам.

Контекст scope: [context/scope.md](context/scope.md) · [arch mvp-scope-map](../arch/docs/onboarding/outstaffing/mvp-scope-map.md).

**1. Список вакансий**
- KPI-карточки: иконка + colored left border, 3 метрики в ряд
- Список вакансий: card-list (заказчик · статус · таймеры · счётчики · отказы)

**2. Воронка**
- Kanban full-width · drawer по клику на карточку
- 5 колонок: AI · проверка · готово · отправлено · отказ
- Действия в drawer зависят от стадии (без DOCX на ранних этапах)

**3. Резюме**
- Две колонки «было» и «стало», изменения подсвечены
- Green highlights для изменений
- Sticky action bar внизу

**Навигация к экрану 4:**
- Список вакансий → кнопка **История** у DevOps Engineer
- Воронка → вкладка **История и отправки** (или кнопка в шапке, или «Статусы →» в колонке «Отправлено»)
- Резюме → кнопка **Отправлено заказчику →**

**4. Карточка вакансии / история**
- Только лента событий + summary отправок
- Select фильтр по кандидату · отказы скрыты по умолчанию

**5. Банк резюме**
- Календарь: недели × люди, % загрузки (AppSheet)
- Список: быстрый поиск свободных

## Presale-nav

Светлая полоска сверху (`#ffffff`, border-bottom) — навигация между экранами прототипа. **Не часть продукта.**
